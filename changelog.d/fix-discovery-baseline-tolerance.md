Discovery now confirms a carried input bound when the provider's own count of the re-tested prompt falls within the bound's width, instead of requiring it to land at or above the bound. The provider counts an identical prompt a few tokens differently on each call, so confirmations were a coin flip: `gemini-flash-lite-latest` spent a whole six-probe session re-testing 84,950 and never climbed. A canary that stays inconclusive now records its report-safe reason and HTTP status in canary memory, so a route like `gemini-flash-latest` can be diagnosed.
